# ERD CLOUD

erdcloud.com 스타일의 웹 기반 ERD(개체-관계 다이어그램) 편집기입니다.
프레임워크·빌드 도구 없이 순수 HTML/CSS/JS로 만들어졌고, 모든 데이터는 브라우저 localStorage에 저장됩니다.

## 실행 방법

```bash
# 방법 1: index.html을 브라우저로 바로 열기 (더블클릭)

# 방법 2: 로컬 서버로 실행 (개발 시 권장 — 캐시 없이 항상 최신 파일 제공)
python3 server.py
# → http://localhost:5199 접속
```

## 기능

### 대시보드
- ERD 목록 (이름 검색, 수정일 정렬)
- 새 ERD 생성 / 이름 변경 / 복제 / 삭제
- JSON 파일 가져오기

### 편집기
- **테이블(엔티티)**: 논리명/물리명, 헤더 색상, 드래그 이동
- **컬럼**: 논리명/물리명, 타입, PK, NOT NULL, 코멘트, 순서 변경
- **인라인 편집**: 테이블 이름/컬럼 텍스트를 한 번 클릭하면 그 자리에서 바로 수정 (Enter 확정, Esc 취소)
- **타입 선택 팝업**: 컬럼 타입을 클릭하면 타입 목록이 바로 열림 (검색·직접 입력 가능)
- **컬럼 순서 드래그**: 행에 마우스를 올리면 나타나는 왼쪽 그립(⋮⋮)을 끌어 순서 변경
- **속성 패널**: 테이블 헤더의 ⋯ 버튼으로 열기 — PK/NN, 코멘트, 색상, 컬럼 추가/삭제 등 세부 속성 편집
- **관계**: 1:1 / 1:N × 식별(실선) / 비식별(점선), 까마귀발 표기법
  - 관계 버튼 클릭 → 부모 테이블 → 자식 테이블 순서로 클릭
  - 관계 생성 시 부모 PK가 자식 테이블에 FK 컬럼으로 자동 전파
  - 자기 참조 관계 지원
- **메모**: 색상 변경, 크기 조절
- **캔버스**: 팬(빈 곳 드래그/휠), 줌(Ctrl+휠, 버튼), 전체 보기
- **실행 취소/다시 실행**: Ctrl+Z / Ctrl+Shift+Z
- **자동 저장** (localStorage)

### 내보내기
- **SQL**: MySQL CREATE TABLE + FOREIGN KEY DDL (코멘트 포함)
- **PNG**: 다이어그램 이미지
- **JSON**: 백업/공유용 (대시보드에서 다시 가져오기 가능)

## 단축키

| 키 | 동작 |
|---|---|
| `Delete` / `Backspace` | 선택 항목 삭제 |
| `Esc` | 선택 해제 / 관계 모드 취소 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행 취소 / 다시 실행 |
| `Ctrl+S` | 즉시 저장 |
| `Ctrl+휠` | 확대/축소 |
| 클릭(테이블/컬럼 텍스트) | 그 자리에서 바로 수정 |

## 한계

- 서버가 없는 로컬 전용 버전이라 로그인·실시간 협업·공유 링크는 없습니다. 공유는 JSON 내보내기/가져오기를 이용하세요.
- 관계 생성 이후 부모 PK를 추가/변경해도 자식 테이블에 자동 반영되지 않습니다.
